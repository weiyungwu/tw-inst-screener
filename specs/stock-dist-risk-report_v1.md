# 疑似出貨風險與持股防守報告 Skill v1.2（資料包版）

> v1.1 → v1.2：新增**四維偏空燈號儀表板**，燈號直接引用資料包（`台股籌碼資料` v1.3，照抄 API 的 `bear_lights`），和網站出貨頁顯示的相同；四維偏多紅燈 ≥ 3 列為反證「走勢仍強」。

> v1.0 → v1.1：參考「台股四維多空共振分析 Skill v1.0」，新增**結構檢查**（結論分層、假突破／假跌破、反證與替代解釋）與**強化／推翻條件**。新增的判斷全部用資料包的數字照規則算，**不改變第 5 節的風險等級**。差異見第 2 節末。

## 1. Skill 名稱
stock-dist-risk-report

## 2. 目的
接收 `台股籌碼資料` Skill 產出的**單檔資料包**（任務 C，含「出貨風險」一節），完成三件事：

1. **風險儀表板**：把出貨掃描器已算好的五個群組得分，配上依據的數字，說清楚是哪些現象同時出現。
2. **防守盲點**：找出這份風險判斷最可能錯在哪裡，以及資料包沒有涵蓋、要自己確認的事；並用結構檢查列出反證、替代解釋，以及什麼情況代表判斷錯了。
3. **雙軌劇本**：空手者「現在先不要做什麼、等什麼條件」；持股者的反彈減碼區、減碼觀察線、最後防守線。

本 Skill 取代原本的「台股空方交易與防守策略專家」。差別與理由：

| 原版 | 本版 | 理由 |
|---|---|---|
| 自行評 1～10 分、7 分成立 | 直接引用出貨掃描器的分數、覆蓋率與階段 | 同一檔股票不會出現兩套互相矛盾的結論；掃描器的規則可以重算、有回測 |
| 輸入要求券商分點、主力買超比率、POC、年線、強制回補日、處置股 | 只用資料包有的欄位；沒有的列入「資料包未涵蓋」由使用者自行確認 | 這些欄位 API 沒有，模型只能自己編 |
| 軌道 A 給放空進場價、停損、目標價 | **不提供任何放空價位** | 回測（2026-04～10）：名單 5 日報酬和其他個股幾乎沒有差異，期間最大上漲幅度也相同，放空價位沒有依據 |
| 軌道 B 持股防守 | 保留，價位依公式從均線與高低點推導 | 和「20 日風險提示」的定位一致 |

分工：

| 角色 | 負責 | 回答的問題 |
|---|---|---|
| tw-inst-screener（出貨掃描器） | 評分、分類、產資料包 | 有沒有疑似出貨的現象同時出現？ |
| 本 Skill 第 5 節 | 風險儀表板、結構檢查 | 是哪些現象？資料齊不齊？價量結構支不支持？有沒有反證？ |
| 本 Skill 第 6 節 | 防守盲點 | 這個判斷為什麼可能錯？ |
| 本 Skill 第 7～8 節 | 價位與報告 | 持股者在哪裡減碼、哪裡防守？什麼情況代表判斷錯了？ |

### v1.1 採用與不採用（對照「台股四維多空共振分析 Skill v1.0」）

| 該 Skill 的做法 | v1.1 | 理由 |

## 4. 資料規則
1. 報告中的價格、成交量、均線、籌碼、借券數字**只能來自資料包**，不可用記憶或其他網站補值、覆蓋。
2. 資料包是**收盤後日資料**，報告開頭必須寫「資料日期 YYYY/MM/DD 收盤」。
3. 資料包寫「資料不足」的欄位：相關項目標 ⚪ 資料不足，不可推論、不可當成 0。
4. 「沒有出貨資料」（`distribution` 為 null）時**不產生風險結論**，只輸出一行：「XXXX 沒有出貨評分資料，無法判斷，不代表沒有出貨風險。」
5. 用語一律是「**疑似出貨風險訊號**」。不可寫「主力正在出貨」「主力倒貨」「確定做頭」；官方資料只能確認法人淨賣出、借券餘額增加這類事實，不能證明是誰在賣、為什麼賣。
6. **期間只談 20 日左右**。不可推論隔日、本週的漲跌，不可提供放空進場價、放空停損價、放空目標價或放空時點。
7. **事實和推論分開寫**。「已確認的事實」只能是資料包的數字加上日期（例如「20 天中 14 天外資＋投信淨賣超」），不加形容詞；其他判斷都要標明屬於第 5 節結論分層的哪一層。
8. 不可把**借券**等同放空（借券也用於避險、套利、交割），不可把**法人賣超**等同主力做空（可能是調節、換股或避險）。資料包**沒有融券餘額**，不可用券資比推估融券增減。

## 5. 風險儀表板

### 風險等級（依出貨掃描器的階段與資料狀態定調）
| 出貨階段 | 條件 | 風險等級 | 報告定調 |
|---|---|---|---|
| 疑似出貨 `DISTRIBUTION` | 借券已計入 | **高** | 多項疑似出貨現象同時出現 |
| 疑似出貨 `DISTRIBUTION` | 帶 `sbl_pending` | **高（借券未計入）** | 同上，並註明借券分數尚未計入，22:45 後可能變動 |
| 注意 `CAUTION` | — | **中** | 部分現象出現 |
| 暫定 `PROVISIONAL` | — | **待確認** | 分數夠但資料不齊，寫出缺哪些資料，不下結論 |
| 已大幅下跌 `COLLAPSED` | — | **不適用** | 已大跌一段，不適用高檔派發判斷；**不代表風險解除**，只輸出儀表板與持股者防守線 |
| 中性 `NEUTRAL` | — | **低** | 目前沒有多項現象同時出現；帶 `low_coverage` 時改寫「資料不足，無法判斷」 |
| 排除 `EXCLUDED` | — | **不評** | 成交值不足或資料不足，不出報告 |

### 五群組儀表板
每一群組寫出資料包中的得分與依據的數字。得分 0 而且該群組有「資料不足」欄位時標 ⚪，不可解讀成沒有風險。

| 群組 | 滿分 | 依據的數字（取自資料包） |
|---|---|---|
| 法人調節 | 30 | 外資＋投信 20 日淨買超 % 股本、20 天中淨賣超天數、投信 % 股本、近 5 日外資＋投信合計 |
| 籌碼分散 | 25 | 大戶比例連續週減週數、大戶 4 週變化、股東人數 4 週變化（集保週數少，門檻尚未經回測驗證，要註明） |
| 高檔轉弱 | 20 | 距 60 日最高、季線乖離、是否跌破月線 |
| 量能異常 | 10 | 20 日內帶量長黑天數 |
| 信用與借券 | 15 | 借券 20 日增加 % 股本、借券餘額占股本、融資 20 日變化；券資比只顯示、不計分 |

### 四維偏空燈號（v1.2）

直接引用資料包「出貨風險」一節的四維偏空燈號，**不自己重算**，和網站出貨頁一致。燈號只描述哪些地方已經轉弱，**不改變風險等級**，也不能證明是誰在賣。

| 狀態 | 符號 | 意思 |
|---|---|---|
| 已轉弱 | 🟢 | 偏空條件成立（台股綠跌慣例） |
| 還沒轉弱 | ⭕ | 偏空條件不成立 |
| 資料不足 | ⚪ | 不可當成還沒轉弱 |

| 燈 | 條件（由程式判斷，列出供讀者理解） |
|---|---|
| 籌碼 | 20 日法人淨賣超 ≥ 股本 0.2%、20 天內賣超 ≥ 10 天，而且近 5 日合計仍是賣超 |
| 量能 | 當天量 ≥ 前 5 日均量 × 1.5 且收黑，或 20 日內有帶量長黑 |
| 均線 | 收盤 < MA20，而且 MA5 < MA20 |
| 型態 | 收盤 < 前 19 日最低，或疑似假突破 |

- 均線燈和結構檢查「趨勢偏空」的前兩項（跌破月線、短均線在下）同時成立是同一件事；型態燈的疑似假突破和下方「疑似假突破：偏高」同一規則。兩邊不一致時以資料包的燈號為準，並在報告中註明。
- 資料包寫「沒有偏空燈號資料」時，這一欄整欄寫 ⚪，不可自行判斷。
- 四維偏多紅燈數 ≥ 3 時，列為反證「走勢仍強」（見下方反證表）。

### 結構檢查（v1.1）

只用資料包「近 20 日日 K」與均線計算。日 K 不足 20 筆時，本節各項標 ⚪ 資料不足。

下文代號：日 K 由舊到新為第 1～20 天；**前段** = 第 1～10 天，**近段** = 第 11～20 天；`C` 最新收盤，`R` = 前段最高價，`S` = 前段最低價，`V5` = 前 5 日均量（資料包已提供）。上漲日／下跌日 = 收盤高於／低於前一天收盤（第 2～20 天，共 19 天）。

**結構檢查只描述價量，不改變風險等級。** 結構和風險等級方向不一致時，列為盲點「結構與評分不一致」（第 6 節），不可自行調整等級。以下門檻為初始規則，**尚未經回測驗證**，報告中要註明。

#### 結論分層
報告中的每個判斷都歸到以下其中一層，不可把第 2～4 層寫成第 1 層。

| 層級 | 內容 | 判定 |
|---|---|---|
| 1. 已確認的事實 | 資料包的原始數字與日期 | 直接引用，不評等級 |
| 2. 趨勢偏空 | 價格、均線、高低點的下行結構 | 下表 4 項成立幾項：0～1 低、2 中、3～4 高 |
| 3. 賣壓增加 | 量價與法人賣出 | 下表 3 項成立幾項：0 低、1 中、2～3 高 |
| 4. 疑似出貨風險訊號 | 多項現象同時出現 | **直接引用第 5 節風險等級**，不另外評 |

趨勢偏空（4 項）：

| 項目 | 成立條件 |
|---|---|
| 跌破月線 | `C` < MA20 |
| 短均線在下 | MA5 < MA20 |
| 跌破季線 | `C` < MA60 |
| 高低點下移 | 近段最高 < `R`，而且近段最低 < `S` |

賣壓增加（3 項）：

| 項目 | 成立條件 |
|---|---|
| 下跌放量 | 下跌日平均量 ≥ 上漲日平均量 × 1.3（上漲日或下跌日不足 3 天時標 ⚪） |
| 帶量長黑 | 20 日內帶量長黑 ≥ 1 天 |
| 近期法人仍賣 | 近 5 日外資＋投信合計 < 0 |

#### 假突破／假跌破檢查

| 檢查 | 判定 | 條件 |
|---|---|---|
| 疑似假突破 | **偏高** | 近段曾有收盤 > `R`，而且最新收盤 `C` < `R`（收盤站上前高後又跌回） |
| | **待確認** | 近段只有盤中最高 > `R`、沒有收盤站上，而且 `C` < `R` |
| | **無** | 其他情況 |
| 疑似假跌破 | **偏高** | 近段曾有收盤 < `S`，而且 `C` ≥ `S`（收盤跌破前低後又收復） |
| | **待確認** | 近段只有盤中最低 < `S`、沒有收盤跌破，而且 `C` ≥ `S` |
| | **無** | 其他情況 |

- 寫出 `R`、`S` 的價位與日期，以及突破／跌破那天的量是否 ≥ `V5` × 1.5（只作補充，不改變判定）。
- **疑似假跌破是反證**：判定為偏高或待確認時，一定要列進反證，並說明支撐已收復、賣壓可能被承接。
- 疑似假突破代表追高買盤失敗，可以支持風險判斷，但仍不能證明是誰在賣。

#### 反證與替代解釋
逐項檢查，成立的都要列出並附數字。全部不成立時寫「資料包內未發現反證」，但**替代解釋一定要寫**。

| 反證 | 成立條件 |
|---|---|
| 支撐已收復 | 疑似假跌破為偏高或待確認 |
| 仍在月線之上 | `C` ≥ MA20 |
| 近期法人回補 | 近 5 日外資＋投信合計 > 0 |
| 上漲量較大 | 上漲日平均量 > 下跌日平均量 |
| 吸籌訊號並存 | 吸籌掃描階段為吸籌或觀察 |
| 走勢仍強 | 四維偏多紅燈數 ≥ 3（資料包「出貨風險」一節） |

替代解釋（依成立的群組挑選，至少寫一項）：
- 法人調節：賣超可能是調節、換股、作帳或避險，不一定看壞這檔股票。
- 信用與借券：借券增加可能用於避險、套利或交割，不一定是新增的看空部位。
- 高檔轉弱：可能只是大盤或同產業一起回落（回測中名單檔數和大盤漲跌高度相關）。
- 籌碼分散：大戶比例下降可能來自轉帳、信託或員工持股異動，集保資料無法分辨。

## 6. 防守盲點掃描

逐項檢查下表。**觸發**的項目才列入，依「判斷錯誤時的傷害」排出 Top 3（不足 3 項就列實際觸發的）。每項都要附上觸發的數字。最後一定要列「資料包未涵蓋」。

### 維度 A：認知（資料可信嗎？）
| 盲點 | 觸發條件 |
|---|---|
| 借券未計入 | 借券資料狀態為「當天尚未公布」 |
| 資料覆蓋不足 | 覆蓋率 < 85%，或有任何「資料不足」欄位 |
| 集保不可靠 | 集保累積不足 4 週 |
| 賣壓集中 | 近 5 日三大法人表中，單日外資＋投信賣超占 5 日合計的一半以上 |
| 自營商主導 | 20 日自營商 % 股本的絕對值大於外資＋投信（多為避險，不列為主力） |

### 維度 B：邏輯（現象推得出風險嗎？）
| 盲點 | 觸發條件 |
|---|---|
| 多空訊號矛盾 | 吸籌掃描階段為吸籌或觀察 |
| 跟著大盤 | **每份報告都要列**：回測中名單檔數和大盤漲跌高度相關（ρ ≈ 0.56），要自行確認大盤狀態 |
| 下方支撐緊鄰 | 收盤距最高的支撐 ≤ 3%（容易出現反彈，見第 7 節） |
| 已大幅回落 | 距 60 日最高 ≤ −15%（高檔轉弱的回落項不再給分，跌勢可能已反映一段） |
| 結構與評分不一致 | 風險等級為高或中，但趨勢偏空為「低」、四維偏空燈 0 顆；或疑似假跌破為「偏高」 |

### 維度 C：執行（持股者做得到嗎？）
| 盲點 | 觸發條件 |
|---|---|
| 軋空／反彈動能 | 券資比 ≥ 30%：融券回補可能推升股價，持股者不要在急跌後恐慌殺低 |
| 流動性不足 | 20 日平均成交值 < 0.5 億元（減碼容易滑價） |
| 防守線太遠 | 收盤到最後防守線的跌幅 > 10% |

### 資料包未涵蓋（每份報告都要列）
融券餘額與融券強制回補日、股東會與除權息時程、處置股或全額交割、券商分點、財報與產業消息（公開資訊觀測站重大訊息）、週線、大盤。請使用者自行確認。

### 信心等級
高（借券已計入、覆蓋率 100%、集保 ≥ 4 週）／中（缺一項）／低（缺兩項以上）。

## 7. 價位計算

全部從資料包的均線與 20／60 日高低點推導。**所有價位都要依台股升降單位取整**（支撐往下取、壓力往上取）：

| 價格 | 未滿 10 | 10～50 | 50～100 | 100～500 | 500～1000 | 1000 以上 |
|---|---|---|---|---|---|---|
| 單位 | 0.01 | 0.05 | 0.1 | 0.5 | 1 | 5 |

| 價位 | 計算方式 |
|---|---|
| **支撐候選** | MA5、MA10、MA20、MA60、20 日最低、60 日最低，只取**低於**收盤的值，由高到低排序 |
| **壓力候選** | MA5、MA10、MA20、MA60、20 日最高、60 日最高，只取**高於**收盤的值，由低到高排序 |
| **反彈減碼區** | 下限 = 最近的壓力；上限 = 第二近的壓力。只有一個壓力時，上限 = 下限 × 1.03 |
| **減碼觀察線** | 最高的支撐。**收盤**跌破時提高警戒 |
| **最後防守線** | 第二高的支撐；只有一個支撐時，= 減碼觀察線 × 0.97。**收盤**跌破時依自己的出場規則處理 |
| **風險解除觀察條件** | 收盤重新站上 MA20，而且近 5 日外資＋投信合計轉為正數 |
| **風險強化條件** | 收盤跌破減碼觀察線，而且當日量 ≥ `V5` × 1.5；或借券資料補齊後信用與借券分數上升 |

### 推翻條件（判斷可能錯了）
以下任一成立時，報告要寫「本次風險判斷可能已不成立，應重新評估」，不可只保留支持原結論的證據：
1. 符合風險解除觀察條件。
2. 收盤站上 `R`（第 5 節的前段最高價）。
3. 出貨階段下修為中性 `NEUTRAL`。
4. 疑似假跌破由「待確認」變成「偏高」。

順序必須成立：最後防守線 < 減碼觀察線 < 收盤 < 反彈減碼區下限 ≤ 上限。沒有支撐或壓力時，該價位寫「資料包內沒有可用的支撐／壓力」，不可自行假設。

## 10. 核心原則
> **掃描器負責判斷，本 Skill 負責說清楚依據和盲點。**

> **只談 20 日的風險提示，不給放空時點。**

> **沒有資料就說沒有資料，不等於沒有風險。**

> **每個結論都要寫出什麼情況代表它錯了。**
